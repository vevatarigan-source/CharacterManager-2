
# Character Manager — Mini-Challenge

## Deskripsi
Character Manager adalah aplikasi Java Swing untuk menampilkan dan
mengelola daftar karakter menggunakan konsep Object-Oriented Programming.

## Fitur
- Menampilkan minimal lima karakter.
- Menampilkan tipe, level, HP, attack, dan mana.
- Menghitung rata-rata level secara otomatis.
- Menyediakan tombol Refresh Data.
- Mengembalikan salinan daftar karakter untuk menjaga enkapsulasi.

## Perhitungan Rata-rata Level
Rata-rata level dihitung dengan rumus:

Rata-rata = Jumlah seluruh level / Jumlah karakter

Jika daftar kosong, nilai rata-rata adalah 0.

## Pengujian
Sebelum perubahan:
Level karakter = 5, 8, 6, 7, 4
Rata-rata = 30 / 5 = 6.00

Sesudah perubahan:
Level karakter = 5, 8, 6, 7, 10
Rata-rata = 36 / 5 = 7.20
